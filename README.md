# Blog Website

A full-stack blog web application built with **Python and Flask** as a learning project to explore Flask web development and understand how backend and frontend components work together.

The frontend is built using **HTML, CSS, and Jinja2 templates**, while Flask handles the backend logic, routing, and dynamic data rendering.

The website's design and layout are inspired by the [W3Schools W3.CSS Blog Template](https://www.w3schools.com/w3css/tryw3css_templates_blog.htm).

## Features

- Dynamic content rendering using Jinja2.
- Reusable HTML templates.
- Data management using Python dictionaries and lists.
- Dynamic navigation and conditional rendering.
- Static file management for images, CSS, and other assets.
- Flask routing and template integration.

## Technologies Used

- **Python** – Backend programming.
- **Flask** – Web framework.
- **Jinja2** – Template engine.
- **HTML5** – Page structure.
- **CSS3** – Styling.
- **uv** – Python package and project management.

## Getting Started

### 1. Clone the repository

```bash
git clone git@github.com:Xushnudd/flask_web.git
cd flask_web
```

### 2. Install dependencies

```bash
uv sync
```

### 3. Run the application

```bash
uv run main.py
```

### 4. Open in your browser

Visit:

```text
http://127.0.0.1:5000
```

## Project Purpose

This project was created primarily for educational purposes while learning Flask. It provides practical experience with Flask routing, Jinja2 templating, dynamic data rendering, and integrating frontend templates with backend logic.
